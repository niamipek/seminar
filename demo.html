Bảng đối chiếu kỹ thuật cốt lõi

        

          

            
              

                Tiêu chí
                Redis
                Memcached
              

            
            
              

                Mô hình xử lý luồng
                Single-threaded Event Loop (I/O Multiplexing)
                Multi-threaded (tận dụng tối đa nhiều CPU cores)
              

              

                Cấu trúc dữ liệu
                String, Hash, List, Set, Sorted Set, Bitmaps, Streams...
                Thuần túy Key-Value (String / Raw Bytes)
              

              

                Lưu trữ bền vững (Persistence)
                RDB Snapshot + AOF log (khôi phục sau restart)
                Không có (Volatile in-memory - mất 100% khi tắt)
              

              

                Giới hạn kích thước Value
                Tối đa 512 MB / value
                Mặc định tối đa 1 MB / value
              

              

                Thao tác cấu trúc con
                Sửa trực tiếp trên server (HSET, HINCRBY, LPUSH...)
                Client phải tải toàn bộ JSON về, sửa rồi đẩy lại
              

              

                Replication & Clustering
                Master-Replica, Redis Sentinel, Redis Cluster
                Không có sẵn (dựa vào client consistent hashing)
              

              

                Tính năng nâng cao
                Pub/Sub, Lua Scripting, Transactions, Geospatial...
                Chỉ get/set/cas, cực kỳ tinh gọn cho cache tĩnh
